# Introdução ao GitHub

_Comece a usar o GitHub em menos de uma hora._

## Boas-vindas

Pessoas do mundo todo usam o GitHub para criar algumas das tecnologias mais avançadas que existem. Seja para visualizar dados ou criar um jogo novo, o GitHub tem uma comunidade inteira e um conjunto de ferramentas que podem ajudar você a fazer isso ainda melhor. Este exercício, "Introdução ao GitHub", mostra tudo o que você precisa para começar a contribuir em menos de uma hora.

- **Para quem é**: pessoas que estão começando a programar, novos usuários do GitHub e estudantes.
- **O que você vai aprender**: vamos apresentar repositórios, branches (ramificações), commits e pull requests (solicitações de mesclagem).
- **O que você vai criar**: um pequeno arquivo Markdown que você pode usar como o [README do seu perfil](https://docs.github.com/pt/account-and-profile/how-tos/profile-customization/managing-your-profile-readme).
- **Pré-requisitos**: nenhum. Este exercício é uma ótima introdução para o seu primeiro dia no GitHub.
- **Duração**: menos de uma hora.

Neste exercício, você vai:

1. Criar um branch
2. Fazer o commit de um arquivo
3. Abrir um pull request
4. Fazer o merge do seu pull request

### Como Começar Este Exercício

Copie o exercício para a sua conta clicando no botão abaixo. Depois, espere **cerca de 20 segundos** enquanto a Mona, a mascote do GitHub, prepara a primeira lição e **atualize a página**.

<summary>Está com dificuldades? 🤷</summary><br/>

Ao copiar o exercício, recomendamos estas configurações:

- Em **Owner** (Proprietário), escolha a sua conta pessoal ou uma organização para hospedar o repositório.

- Recomendamos criar um repositório **Public** (Público), porque repositórios privados consomem minutos do GitHub Actions ("ferramenta de automação do GitHub").

Se o exercício não ficar pronto em 20 segundos, confira a aba [Actions](../../actions) do seu repositório.

- Veja se há algum job ("tarefa automática") em execução. Às vezes ele só demora um pouco mais.

- Se a página mostrar um job com falha, avise o seu instrutor.
